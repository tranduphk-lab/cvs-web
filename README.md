# Cavisi — Dược Mỹ Phẩm Chăm Sóc Hệ Vi Sinh Da Đầu

Website chính thức của thương hiệu Cavisi — Định vị **Scalp-first** và giải pháp chăm sóc da đầu 2 bước chuẩn khoa học: **Làm sạch nền (Cavisi Shampoo)** & **Cân bằng hệ vi sinh (Cavisi Spray)**.

## 🚀 Khởi chạy Local Server

```bash
# Khởi chạy máy chủ Node.js cục bộ
node server.js
```
Truy cập: `http://localhost:3000`

---

## 📁 Cấu trúc thư mục

- `_web/`: Toàn bộ mã nguồn giao diện website hoàn chỉnh:
  - `index.html`: Trang chủ (Scalp-first, routine, bộ đôi sản phẩm, FAQ, ...)
  - `co-che/`: Khoa học cơ chế 2 bước, sơ đồ 3D y khoa, Postbiotic men vỏ liễu
  - `san-pham/`: Danh mục sản phẩm Cavisi Microbiome Care
  - `san-pham/shampoo/`: Chi tiết Cavisi Shampoo 250ml, bảng INCI, quy trình gội chuẩn
  - `san-pham/spray/`: Chi tiết Cavisi Spray 30ml, bảng INCI và hướng dẫn dùng leave-on đã xác nhận
  - `thuong-hieu/`: Triết lý thương hiệu, nhà máy sản xuất Butter-C
  - `lien-he/`: Kênh liên hệ, chính sách đổi trả, hotline, Zalo và form đặt hàng
  - `styles.css`: Hệ thống thiết kế chuẩn Dược Mỹ phẩm, font Inter tinh giản, responsive hoàn hảo
  - `script.js`: Xử lý tương tác, sticky header, mobile menu, accordion FAQ, contact widget, scroll to top
  - `assets/`: Tài nguyên hình ảnh, mô hình bao bì, icon SVG tối ưu
- `Cavisi/`: Tài liệu nhận diện thương hiệu, thông tin sản phẩm và tư liệu gốc
- `server.js`: Web server Node.js phục vụ kiểm thử cục bộ
