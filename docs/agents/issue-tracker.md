# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

Repository: `tranduphk-lab/cvs-web`

## Conventions

- Create, read, comment on, label, and close issues using `gh issue`.
- Infer the repository from the configured Git remote.
- Pull requests are not part of the triage request surface.
- When a skill says "publish to the issue tracker", create a GitHub issue.
- When a skill says "fetch the relevant ticket", read the GitHub issue and its comments.

## Wayfinding

Use one GitHub issue as the map and linked sub-issues as tickets. Represent blocking relationships using native GitHub issue dependencies where available, with task-list and `Blocked by:` references as fallback.
